# Data handling

Place challenge-provided files locally under this directory using the documented source filenames. Do not commit raw or processed challenge data until the challenge terms and redistribution licence have been checked.

For every file, record:
- original filename and source
- download/access date
- licence / challenge permission
- checksum
- row count and schema
- transformations and exclusions

Keep raw data immutable. Derived datasets must be reproducible from code and configuration. Do not put credentials, personal information, or restricted data in this repository.
